## วิธีใช้งาน
1. **ตัวกรอง (Filter)** — เลือก ภาค / จังหวัด / เดือน / ประเภทรถ / มูลเหตุ / สภาพอากาศ จากแถบด้านบน ทุกกราฟและตัวเลขสรุปจะอัปเดตพร้อมกัน ตัวกรองที่ใช้อยู่แสดงเป็นป้าย (กด × เพื่อลบ) หรือกด "ล้างตัวกรอง"
2. **คลิกที่กราฟเพื่อกรอง (Cross-filter)** — คลิกชิ้นในกราฟวงแหวนมูลเหตุ หรือแท่งประเภทรถ เพื่อกรองทั้งหน้า คลิกซ้ำเพื่อยกเลิก
3. **Drilldown**
   - กราฟเส้นรายเดือน → คลิกจุดของเดือน เพื่อดูรายวันของเดือนนั้น (ปุ่ม "← ทั้งปี" เพื่อกลับ)
   - กราฟแท่งพื้นที่ → คลิกภาค เพื่อดูรายจังหวัดในภาคนั้น → คลิกจังหวัดเพื่อกรอง (มี breadcrumb ให้ย้อนกลับ)
4. **Zoom** — ซูม/เลื่อนแผนที่ได้, ลากเลือกช่วงบนกราฟรายวันเพื่อซูม ดับเบิลคลิกเพื่อรีเซ็ต
5. **Tooltip** — ชี้เมาส์ (หรือแตะบนมือถือ) ที่กราฟใดก็ได้เพื่อดูรายละเอียด จุดบนแผนที่แสดงวันเวลา สายทาง ประเภทรถ มูลเหตุ และจำนวนผู้เสียชีวิต/บาดเจ็บ
6. **Transition** — กราฟแท่ง/เส้นเคลื่อนไหวเมื่อข้อมูลเปลี่ยน, ตัวเลข KPI นับขึ้น/ลงแบบแอนิเมชัน
7. ปุ่มสลับตัวชี้วัด: กราฟแนวโน้ม (จำนวนครั้ง / ผู้เสียชีวิต) และกราฟประเภทรถ (จำนวนครั้ง / ความรุนแรง = ผู้เสียชีวิตต่อ 100 ครั้ง)

## กราฟที่ใช้ (5 รูปแบบ)
| กราฟ | คำถามที่ตอบ | Interactivity |
|---|---|---|
| Line chart (area) | อุบัติเหตุเกิดมากช่วงไหนของปี | tooltip, drilldown เดือน→วัน, zoom, transition |
| Horizontal bar chart | ภาค/จังหวัดไหนเกิดเหตุมาก | tooltip, drilldown ภาค→จังหวัด, cross-filter, transition |
| Scatter map | จุดเกิดเหตุอยู่ที่ไหน มีผู้เสียชีวิตหรือไม่ | zoom/pan, tooltip, legend toggle |
| Donut chart | มูลเหตุสันนิษฐานหลักคืออะไร | tooltip, cross-filter |
| Heatmap | วันและเวลาไหนเกิดเหตุบ่อย | tooltip |
| Bar chart (ประเภทรถ) | รถประเภทไหนเกิดเหตุมาก/รุนแรงที่สุด | tooltip, cross-filter, สลับตัวชี้วัด, transition |

รองรับหน้าจอหลายขนาด (Responsive): desktop 2 คอลัมน์ → tablet/mobile 1 คอลัมน์, รองรับ Dark mode ตามระบบ

## การใช้ AI ช่วยทำงาน (Prompts)
ใช้ **Claude (Anthropic) ผ่าน claude.ai** ช่วยค้นหา dataset, ตรวจสอบการทำความสะอาดข้อมูล, เขียนสคริปต์เตรียมข้อมูล และเขียนโค้ดเว็บ (HTML/CSS/JavaScript)
ส่วนการเลือก dataset, การตัดสินใจทำความสะอาดข้อมูล และการตรวจสอบผล ทำโดยผู้จัดทำ

Prompts ที่ใช้:
1. หา data set ที่เหมาะสมและ เป็นภาษาไทยให้หน่อย
2. ขอใหม่เพิ่มเติมข้อมูลง่ายๆ กว่านี้ หน่อย
3. clean data set นี้ให้หน่อยและ ได้ ค่า missing จำนวนเท่าไหร
4. ก.ม คือไร ในข้อมูล
5. ลบได้มั้ย
6. เทียบกับ ข้อมูล raw ให้หน่อย ว่า data หายไปเท่าไหร และเราสามารถนำ data set นี้ไปวิเคราะห์อะไรได้บ้าง
7. คิดว่า สายทางจำเป็นต้องมีมั้ย
8. ดูให้ใหม่ อีกที่ ว่าครบรึยังและทำตารางเปรียบเทียบกับ ข้อมูล raw
9. ตอนนี้นำ lati กับ longti กลับมาใส่แล้วเหลืออะไรอีก
10. ก.ม สามารถลบได้มั้ย
11. ทำเว็บไซต์นำเสนอข้อมูล โดยมีอย่างน้อย 4 รูปแบบกราฟ/แผนภูมิที่แตกต่างกัน และมีปฏิสัมพันธ์ (interactivity) filter, tooltip, zoom, drilldown, transition และเว็บต้องรองรับการแสดงผลบนหน้าจอขนาดต่างกัน (responsive) ในระดับพื้นฐาน
12. เว็บเปิดไม่ได้
13. กราฟดูงง สีเข้ม อุบัติเหตุมาก แต่อันนี้จาง แต่เยอะ
14. ปรับหน้าเว็บ สี สว่าง
15. ขอ prompt สำหรับผลงานนี้
16. ตกแต่งหน้าเว็บไซต์ให้ดูตรงกับข้อมูลภายใน
17. ขอรายงานกระบวนการทำงาน (ปัญหาและวิธีแก้ บทเรียนที่ได้รับ Prompts และ GPT ที่ใช้)
18. ปรับแก้ใหม่หน่อยให้กดลิงก์ github และมีหน้าเว็บแรกที่สามารถเข้าและออกในการดูข้อมูลต่างๆ ได้ทั้งหมดในไฟล์
19. เอารายงานกระบวนการทำงานมาใส่เพิ่มเติมด้วย
