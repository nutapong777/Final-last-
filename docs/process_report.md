## ขั้นตอนการทำงาน (CRISP-DM)

1. **Business Understanding** — ตั้งคำถาม: อุบัติเหตุบนทางหลวงเกิดขึ้นเมื่อไหร่ ที่ไหน เพราะอะไร และรถประเภทไหนรุนแรงที่สุด
2. **Data Understanding** — เทียบชุดข้อมูลภาษาไทยหลายชุด เลือกข้อมูลปี 2562 ของกระทรวงคมนาคม ตรวจค่า missing (1,839 ค่า) แถวซ้ำ (0) และความหมายของแต่ละคอลัมน์
3. **Data Preparation** — ทำความสะอาดใน Excel ตามตารางด้านล่าง แล้วใช้ Python แปลงเป็น CSV และ JSON (UTF-8) พร้อมเพิ่มคอลัมน์ภาคและช่วงเวลา
4. **Analysis & Visualization** — สร้างเว็บ 5 กราฟด้วย Plotly.js ทุกกราฟกรองร่วมกัน และมีกล่องข้อค้นพบที่คำนวณจากข้อมูล
5. **Evaluation** — ทดสอบบนจอคอม (1366px) และมือถือ (390px) ตรวจว่าการคลิกกรองและ drilldown ทำงานถูกต้อง
6. **Deployment** — อัปโหลดขึ้น GitHub แบบ Public และเปิด GitHub Pages

## บทเรียนที่ได้รับ (Lessons Learned)

บทเรียนสำคัญที่สุดคือ ทุกการตัดสินใจตอนทำความสะอาดข้อมูลส่งผลต่อตัวเลขที่คนดูบนกราฟโดยตรง

1. **ต้องเทียบกับข้อมูลดิบทุกครั้ง** — การลบแถวทำให้ผู้เสียชีวิตหายจากข้อมูล 467 คน ถ้าไม่ทำตาราง raw เทียบ clean จะไม่รู้เลยว่าตัวเลขต่ำกว่าความจริง
2. **"อื่นๆ" ไม่ใช่ค่า missing** — เป็นหมวดหมู่ที่หน่วยงานบันทึกจริง จะลบหรือเก็บก็ได้ แต่ต้องใช้หลักเกณฑ์เดียวกันทุกคอลัมน์และอธิบายเหตุผลได้
3. **อย่าลบคอลัมน์ก่อนรู้ว่าจะทำกราฟอะไร** — พิกัด lat/long เกือบถูกลบ ทั้งที่เป็นสิ่งที่ทำแผนที่ได้ ควรวางแผนกราฟก่อนตัดสินใจตัดคอลัมน์
4. **เลือกกราฟให้ตรงคำถาม** — กราฟเส้นตอบ "เมื่อไหร่" แผนที่ตอบ "ที่ไหน" heatmap ตอบ "วันและเวลาไหน" การเลือกจากคำถามทำให้ได้ข้อค้นพบชัดกว่าเลือกจากความสวย
5. **สีต้องสื่อความหมายเดียว** — heatmap ที่สีกลับด้านทำให้อ่านผิด ต้องมีคำอธิบายสีและหน่วยกำกับเสมอ
6. **ทดสอบเหมือนผู้ใช้จริง** — เว็บที่ทำงานผ่าน server อาจเปิดไม่ได้เมื่อดับเบิลคลิกไฟล์ ควรทดสอบทั้งเปิดในเครื่อง บน GitHub Pages และบนมือถือ
7. **ใช้ AI เป็นผู้ช่วยตรวจ ไม่ใช่ผู้ตัดสินใจ** — AI ช่วยหาจุดผิดและเขียนโค้ดได้เร็ว แต่การเลือกว่าจะลบอะไร เก็บอะไร ผู้จัดทำต้องเข้าใจและอธิบายเองได้

## Prompts และ GPT ที่ใช้ช่วยทำงาน

ใช้ **Claude (Anthropic) ผ่าน claude.ai** เป็นเครื่องมือ AI เพียงตัวเดียว รวม 19 prompts

| ส่วนงาน | AI ช่วย | ผู้จัดทำทำเอง |
| --- | --- | --- |
| Dataset | ค้นหาและเปรียบเทียบชุดข้อมูล | เลือกและดาวน์โหลดข้อมูล |
| Data Cleaning | นับ missing, ตรวจไฟล์ clean เทียบ raw, ทำตารางเปรียบเทียบ | ทำความสะอาดใน Excel และตัดสินใจว่าจะลบ/เก็บอะไร |
| เตรียมข้อมูล | เขียนสคริปต์ Python แปลงเป็น CSV/JSON UTF-8 | รันและตรวจผล |
| เว็บ | เขียน HTML/CSS/JavaScript และกราฟ Plotly.js | ทดสอบ แจ้งปัญหา และกำหนดการปรับแต่ง |
| เผยแพร่ | เขียน README และรายงาน | อัปโหลดขึ้น GitHub และตั้งค่า GitHub Pages |

**ช่วงที่ 1 — หา Dataset**

1. หา data set ที่เหมาะสมและ เป็นภาษาไทยให้หน่อย
2. ขอใหม่เพิ่มเติมข้อมูลง่ายๆ กว่านี้ หน่อย

**ช่วงที่ 2 — ทำความสะอาดข้อมูล**

3. clean data set นี้ให้หน่อยและ ได้ ค่า missing จำนวนเท่าไหร
4. ก.ม คือไร ในข้อมูล
5. ลบได้มั้ย
6. เทียบกับ ข้อมูล raw ให้หน่อย ว่า data หายไปเท่าไหร และเราสามารถนำ data set นี้ไปวิเคราะห์อะไรได้บ้าง
7. คิดว่า สายทางจำเป็นต้องมีมั้ย
8. ดูให้ใหม่ อีกที่ ว่าครบรึยังและทำตารางเปรียบเทียบกับ ข้อมูล raw
9. ตอนนี้นำ lati กับ longti กลับมาใส่แล้วเหลืออะไรอีก
10. ก.ม สามารถลบได้มั้ย

**ช่วงที่ 3 — พัฒนาเว็บ**

11. ทำเว็บไซต์นำเสนอข้อมูล โดยมีอย่างน้อย 4 รูปแบบกราฟ/แผนภูมิที่แตกต่างกัน และมีปฏิสัมพันธ์ (interactivity) filter, tooltip, zoom, drilldown, transition และเว็บต้องรองรับการแสดงผลบนหน้าจอขนาดต่างกัน (responsive) ในระดับพื้นฐาน

**ช่วงที่ 4 — แก้ไขและปรับปรุง**

12. เว็บเปิดไม่ได้
13. กราฟดูงง สีเข้ม อุบัติเหตุมาก แต่อันนี้จาง แต่เยอะ
14. ปรับหน้าเว็บ สี สว่าง
15. ขอ prompt สำหรับผลงานนี้
16. ตกแต่งหน้าเว็บไซต์ให้ดูตรงกับข้อมูลภายใน
17. ขอรายงานกระบวนการทำงาน (ปัญหาและวิธีแก้ บทเรียนที่ได้รับ Prompts และ GPT ที่ใช้)
18. ปรับแก้ ใหม่หน่อยให้กด ลิ้ง github และมีหน้าเว็บแรก ที่สามารถเข้าและออกในการดูข้อมูล ต่างได้ทั้งหมดใน ไฟล์
19. เอารายงานกระบวนการทำงานมาใส่เพิ่มเติมด้วย
